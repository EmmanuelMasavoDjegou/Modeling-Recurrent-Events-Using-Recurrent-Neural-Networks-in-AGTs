# data/

Generated by the R preprocessing scripts; git-ignored.

| File | Source | Subjects |
|---|---|---|
| `crc.csv` | `frailtypack::readmission`, colorectal cancer readmission | 403 |
| `cgd.csv` | `survival::cgd`, chronic granulomatous disease | 128 |

Regenerate from the repository root:

```bash
Rscript application/Dataset1_Data_Preprocessing.R   # -> data/crc.csv
Rscript application/Dataset2_Data_Preprocessing.R   # -> data/cgd.csv
```

Both datasets ship with public R packages, so the analyses reproduce end to end
without a data-access request.

## Format

One row per gap, ordered within subject:

| column | meaning |
|---|---|
| `id` | subject identifier; the key the R and Python sides join on |
| `gap_time` | observed gap, strictly positive |
| `event` | event indicator, retained for the R models |
| `delta` | 1 = fully observed gap, 0 = censored; what Python reads |
| `Z1`, `Z2`, `Z3` (`Z4`) | covariates |

`gap_time` must be strictly positive: the AFT models work on the log scale, so
zero gaps are not representable. The preprocessing scripts raise rather than
dropping them, because filtering on one side only would put the Cox and AFT
models on different rows and silently break the pairing that Table 9 depends on.
